# 01 — Heatmaps

Heatmaps de densidad (KDE) para evaluar la presencia espacial de un jugador.
Caso de estudio: Pedri (España) en la UEFA Euro 2020.
Incluye comparativas por tipo de acción, entre partidos y entre jugadores.
Datos: StatsBomb Open Data (`competition_id=55`, `season_id=43`).
Paquete: usa `futbolycodigo.viz_utils`, `branding` y `data_loaders`.
